01Что делает решение

Отвечает на вопросы

по содержанию дисциплин, формулам оценивания, литературе, преподавателям, срокам и связям между курсами — по любому вопросу первокурсника к программам.

Показывает источники

Каждый ответ сопровождается ссылками на конкретные разделы официальных программ на hse.ru — ответ всегда проверяем.

Корпус

25 дисциплин 1 курса ИВТ за 2026/2027: от «Алгебры и геометрии» до проектных семинаров, включая углублённые курсы. Скрейпер скачивает и парсит страницы автоматически.

Три интерфейса

Веб-чат, CLI и API — всё на стандартной библиотеке Python, запускается одной командой без установки зависимостей.

02Как это устроено

вопрос → нормализация (стемминг + синонимы: «матан», «дискретка», «прога»)
      → BM25-поиск по фрагментам программ (~360 чанков)
      → бусты: упомянутая дисциплина ×2.5 + релевантный раздел («Элементы контроля», «Литература»…)
      → краткий ответ: экстрактивная выжимка или внешняя LLM по найденным фрагментам
      → источники: дисциплина + раздел + ссылка

Пайплайн данных

Скрейпер → структурированный JSON (разделы, элементы контроля, литература, метаданные) → чанкинг с очисткой от футера и хлебных крошек.

Гибридный ответ

Офлайн: экстрактивная выжимка ключевых строк. С ключом API — любая OpenAI-совместимая LLM, но строго по найденным фрагментам.

03Почему такой подход

  • Данные — официальные и структурированные. Программы на hse.ru уже содержат ответы в явном виде, поэтому достоверный поиск + выжимка решают задачу точнее и дешевле, чем генерация «из головы» LLM.
  • Проверяемость важнее красоты. Студент должен видеть, откуда взят ответ — каждый ответ ссылается на раздел конкретной программы.
  • RLM-схема (retrieval → LLM → sources). LLM подключается опционально и только переформулирует найденное — галлюцинации сведены к минимуму.
  • Ноль зависимостей. BM25, стеммер и веб-сервер написаны на чистом Python: решение запускается у любого проверяющего одной командой.
  • Офлайн-режим по умолчанию — не нужен ключ API, чтобы попробовать.

06Где решение ошибается

Вопросы вне корпуса

«В какое время идут пары?», «какие дедлайны?» — расписание и дедлайны не входят в программы. Помощник может притянуть нерелевантный фрагмент вместо честного «не знаю».

Агрегация между документами

«Сколько всего кредитов за год?» — нужно просуммировать 25 программ; поиск по фрагментам этого не умеет.

Субъективные вопросы

«Что сложнее: физика или дискретка?» — в корпусе нет основы для сравнения, система всё равно выдаёт «ближайший» текст.

Экстрактивный режим

Иногда — набор строк вместо связного ответа; чувствителен к формулировкам, склейке строк и опечаткам («gjxtve yf ujhtj» не распознаётся).

Базовый vs углублённый

При неоднозначной формулировке может смешать версии курса (кредиты 11 у базовой физики и 9 у углублённой).

Генерация контента

«Напиши конспект лекции» — вне задачи; система выдаёт темы, но не учебный материал.

07Что улучшил бы за два дня

  • 1. Семантический поиск. Заменить/дополнить BM25 эмбеддингами (например, многозязычная sentence-transformers модель): снимет проблемы с синонимами, опечатками и разговорными формулировками.
  • 2. Детектор «вне корпуса». Порог релевантности + классификатор вопроса: честное «этого нет в программах» вместо притянутых фрагментов.
  • 3. Агрегации и сравнения. Прекомпилированная таблица метаданных (кредиты, модули, часы) для ответов типа «сколько кредитов за год».
  • 4. LLM-слоу по умолчанию. Подключить бесплатный OpenAI-совместимый endpoint, чтобы связные ответы были не опцией, а стандартом.
  • 5. Многоходовые вопросы. Декомпозиция вопроса и несколько циклов поиска для «связанных» запросов (пререквизиты → постреквизиты).
