# 🎓 Помощник первокурсника ИВТ МИЭМ НИУ ВШЭ

Прототип ассистента, который отвечает на вопросы первокурсника по содержанию
учебных дисциплин 1 курса образовательной программы «Информатика и
вычислительная техника» (ИВТ) МИЭМ НИУ ВШЭ за 2026/2027 учебный год: темы
курсов, формы контроля и формулы оценивания, литература, преподаватели,
связи между дисциплинами.

**Корпус:** 25 официальных программ дисциплин с сайта
[hse.ru](https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026)
(обязательные курсы 1–4 модулей 1 курса, включая углублённые версии и
индустриальные профили).

## Как это работает

```
вопрос → нормализация (стемминг, синонимы курсов) → BM25-поиск по фрагментам
программ → бусты (упомянутая дисциплина + релевантный раздел) →
краткий ответ (экстрактивная выжимка или внешняя LLM) → список источников
```

- **Поиск:** BM25 на чистом Python + лёгкий стеммер русского языка +
  словарь разговорных названий курсов («матан», «дискретка», «прога»).
- **Ответ:** по умолчанию — экстрактивная выжимка релевантных строк (полностью
  офлайн). Если заданы переменные окружения `LLM_BASE_URL` / `LLM_API_KEY` /
  `LLM_MODEL`, ответ формулирует любая внешняя OpenAI-совместимая LLM — но
  строго по найденным фрагментам программ.
- **Источники:** каждый ответ сопровождается ссылками на конкретные разделы
  официальных программ на hse.ru.
- **Зависимости: нет.** Только стандартная библиотека Python 3.10+.

## Запуск

```bash
# веб-интерфейс (чат) — http://localhost:8000
python3 server.py

# другой порт
python3 server.py 8080

# CLI: разовый вопрос
python3 cli.py "Как сдаётся математический анализ?"

# CLI: интерактивный режим
python3 cli.py

# прогон 30 тестовых вопросов -> docs/test_results.md
python3 tests/run_tests.py

# пересборка корпуса (скачивает актуальные программы с hse.ru)
python3 scraper.py
```

### Подключение внешней LLM (опционально)

```bash
export LLM_BASE_URL="https://api.openai.com/v1"   # или другой OpenAI-совместимый API
export LLM_API_KEY="sk-..."
export LLM_MODEL="gpt-4o-mini"
python3 server.py
```

Без этих переменных помощник работает офлайн в экстрактивном режиме.

## Структура проекта

```
scraper.py            # скачивание и парсинг программ дисциплин -> data/courses.json
server.py             # веб-интерфейс (чат), только stdlib
cli.py                # консольный интерфейс
assistant/
  corpus.py           # чанкинг программ, нормализация, стеммер
  retrieval.py        # BM25-индекс, синонимы курсов, бусты разделов
  answer.py           # конвейер ответа + источники
  llm.py              # опциональный вызов внешней LLM (OpenAI-совместимой)
data/
  courses.json        # спарсенный корпус (25 дисциплин)
  raw/                # исходные HTML страниц программ
tests/
  questions.json      # 30 тестовых вопросов (20 «работает» + 10 «недостатки»)
  run_tests.py        # прогон -> docs/test_results.md
docs/
  test_results.md     # результаты тестирования на 30 вопросах
  presentation.pdf    # презентация решения
```

## Ограничения (известные недостатки)

Полный разбор — в `docs/test_results.md` (вопросы 21–30) и презентации:

1. Не отвечает на вопросы вне корпуса (расписание, дедлайны, проходные баллы) —
   может «притянуть» нерелевантный фрагмент вместо честного «не знаю».
2. Не выполняет агрегацию между документами (например, «сколько всего кредитов
   за год») и не сравнивает курсы.
3. Экстрактивный режим иногда выдаёт набор строк вместо связного ответа,
   чувствителен к формулировке и опечаткам.
4. Путает базовый и углублённый курс, если вопрос сформулирован неоднозначно.
